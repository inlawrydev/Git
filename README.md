# 🔒 Roblox Obfuscator Bot

Discord-бот для обфускации Roblox-скриптов с автозагрузкой на Pastefy.

## Команды

- `/obfuscate_code` — обфускация кода в чате
- `/obfuscate_file` — загрузка .lua файла
- `/ping` — проверка работы
- `/help` — справка

## Деплой на Hugging Face Spaces

1. Создай Space (Docker → Blank)
2. Загрузи все файлы
3. Добавь Secret: `DISCORD_TOKEN`
4. Запусти!

## Требования

- `DISCORD_TOKEN` — обязательно
- `PASTEFY_API_KEY` — опционально (для приватных паст)
